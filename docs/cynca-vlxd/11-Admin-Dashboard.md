# Cynca VLXD - Admin Dashboard UI Guideline

## Overview
Desktop-first dashboard for administrators of the Cynca VLXD Zalo Mini App.

## Design Goals
- Modern blue theme
- 12-column grid
- Large rounded cards (24-28px)
- White background with subtle shadows
- Spacious layout
- Optimized for analytics and operations

## Layout
- Sidebar: 280px
- Header: 88px
- Content padding: 32px
- Gap: 24px

## Sections
1. Sidebar navigation
2. Top header (search, date picker, export, notifications, avatar)
3. KPI cards (Revenue, Orders, Customers, Profit)
4. Revenue line chart
5. Order status donut chart
6. Best-selling products
7. Product category cards
8. Latest orders table
9. Notifications panel

## Color System
Primary: #0B57F0
Background: #F6F9FC
Card: #FFFFFF
Border: #E8EDF6
Success: #10B981
Warning: #F59E0B
Danger: #EF4444

## Typography
Inter / SF Pro Display
Title 34px
Heading 24px
Body 16px
Caption 14px

## Interaction
- Hover scale 1.02
- 180ms transitions
- Smooth chart animations
- Fade-up card loading

## Responsive
Desktop >=1280px only.

## Visual Style
Inspired by Stripe Dashboard, Shopify Admin, Linear and Vercel while maintaining Cynca VLXD blue branding.
